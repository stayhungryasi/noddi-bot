# noddi-bot — 워뇨띠 실시간 추적

디시인사이드 고정닉 **워뇨띠 (uid `rlawo200`)** 의 새 글을 텔레그램 채널(Space8_Investment)로 보내는 봇입니다. 발송 봇은 `noddi_shafer_bot`입니다.

## 보내는 내용
- 제목, 작성 시각, **본문 원문 전체**(길면 나눠서 전송), 원문 링크
- 첨부 이미지: 봇이 직접 내려받아 업로드합니다. 디시 이미지는 링크로는 안 열리기 때문입니다.
- 동영상이 있으면 "원문에서 확인"이라고 표시합니다.
- 원문을 `archive/` 폴더에 보관합니다. 워뇨띠가 나중에 글을 지워도 기록이 남습니다.

## 안전장치
- **uid로 판별**: 닉네임만 같은 유동닉이나 사칭 글은 걸러냅니다.
- **첫 실행 시 과거 글은 보내지 않습니다.** "추적 시작" 메시지 1건만 보냅니다.
- **중복 전송 방지**: 이미 보낸 글 번호는 `state.json`에 기록합니다.
- **수집이 3회 연속 실패하면** 채널로 경고를 보냅니다. 복구되면 복구 알림도 보냅니다.

## 감시 갤러리
- 기본값: 코스피 마이너갤(`kospi`) + 비트코인갤(`bitcoins_new1`)
- 워뇨띠 갤로그 게시글은 비공개라서 갤러리를 직접 감시합니다.
- 갤러리 추가는 워크플로의 `GALLERIES` 값을 고치면 됩니다. 형식: `갤러리ID:종류:표시이름` (종류 `g`=정식갤, `m`=마이너갤, `mini`=미니갤)

## 운영
- GitHub Actions로 5분마다 자동 점검합니다. GitHub 예약 실행 특성상 실제로는 5~15분 간격으로 돌 수 있습니다.
- 공개(Public) 저장소라 Actions 사용 시간은 무제한 무료입니다. 텔레그램 토큰과 채널 ID는 Actions 시크릿에 암호화되어 있어 공개되지 않습니다.
- 수동 실행: Actions 탭 → noddi-watch → Run workflow

## PC 상시 실행 (1분 단위 실시간)
```bash
pip install -r requirements.txt
set TELEGRAM_BOT_TOKEN=봇토큰      # 맥/리눅스는 export
set TELEGRAM_CHAT_ID=채널ID
python noddi_bot.py --loop 60
```
